# Merge First PR and Resolve Intentional Conflict

## Task Brief
Merge your week 1 PR, create a conflicting feature branch, and resolve the conflict with clear commits.

## Scenario
Your team needs to see your first PR merged and a second feature branch that demonstrates conflict resolution skills.

## Deliverables
- Merged PR in main branch
- Feature branch with resolved conflict

## Success Criteria
- First PR successfully merged to main
- Second feature branch created and merged with conflict resolution

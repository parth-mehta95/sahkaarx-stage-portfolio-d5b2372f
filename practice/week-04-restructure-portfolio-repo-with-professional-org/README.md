# Restructure Portfolio Repo with Professional Organization

## Task Brief
Reorganize your existing repo with proper directory structure, add .gitignore, and demonstrate all basic Git commands in a new feature branch.

## Scenario
Your team lead asks you to restructure the portfolio repo for scalability. Add proper organization and document your workflow.

## Deliverables
- Reorganized repo with clear directory structure
- Feature branch with .gitignore and documentation

## Success Criteria
- Repo has logical folder organization
- All basic commands (add, commit, push, pull) demonstrated

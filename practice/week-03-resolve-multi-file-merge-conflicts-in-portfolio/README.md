# Resolve Multi-File Merge Conflicts in Portfolio Repo

## Task Brief
Create overlapping feature branches, trigger multi-file conflicts, and resolve them with documented commit messages demonstrating mastery.

## Scenario
Your team needs to merge two feature branches that modify the same files. Resolve all conflicts and document your strategy.

## Deliverables
- Merged feature branches in main
- Documented conflict resolution commits

## Success Criteria
- All conflicts resolved cleanly
- Commit messages explain resolution choices

# Practice Code Review and Feedback Iteration

## Task Brief
Simulate code review cycle: create a PR, receive feedback, iterate with new commits, and merge.

## Scenario
Your peer reviews your Collections code. Respond to feedback with targeted commits and demonstrate iteration.

## Deliverables
- PR with 3+ commits showing iteration
- Feedback responses documented
- Clean merge to main

## Success Criteria
- Each commit addresses specific feedback
- Commit messages explain changes
- PR merged without conflicts

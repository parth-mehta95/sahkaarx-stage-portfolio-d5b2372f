# Practice Branching Naming Conventions

## Task Brief
Demonstrate professional branch naming conventions and document standards for your portfolio repository.

## Scenario
Your team standardizes branch naming for clarity. Create branches using feature/, bugfix/, and hotfix/ prefixes with descriptive suffixes.

## Deliverables
- 8+ branches using consistent naming
- Naming convention guide in repository
- Examples showing each prefix type

## Success Criteria
- All branches follow chosen convention
- Guide explains prefix meanings and use cases
- Branch names are descriptive and concise

# Practice Multi-Branch Workflow

## Task Brief
Execute a workflow with multiple concurrent feature branches, manage merge order, and resolve any conflicts that arise.

## Scenario
Your code review requires demonstrating proficiency with concurrent branches and merge sequencing. Create overlapping branches and merge strategically.

## Deliverables
- 4+ feature branches with concurrent changes
- Merge sequence documented in commit history
- Conflict resolution if needed

## Success Criteria
- All branches merge successfully to main
- Merge history is clear and logical
- No orphaned or stale branches remain
